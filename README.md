# Skeuo-Silver-Art-Deco

A custom skeuomorphic icon theme for Linux desktop environments with a beautiful vintage silver and Art Deco aesthetic.

## Features
- **Unique Design:** Beautifully crafted embossed silver symbols with detailed historical ornaments.
- **Rich Icon Set:** Includes over 500 hand-tailored system, app, and device icons.
- **High Compatibility:** Perfectly optimized for **KDE Plasma** (supports both Plasma 5 and Plasma 6).
- **Papirus Base:** Built upon the solid foundation of the Papirus icon theme for excellent fallback coverage.

## Installation

You can easily clone this repository directly into your local icons directory. Open your terminal and run:

```bash
mkdir -p ~/.local/share/icons
git clone https://github.com ~/.local/share/icons/Skeuo-Silver-Art-Deco
```

After running the commands, open your **System Settings** -> **Appearance** -> **Icons** and select **Skeuo-Silver-Art-Deco**.
